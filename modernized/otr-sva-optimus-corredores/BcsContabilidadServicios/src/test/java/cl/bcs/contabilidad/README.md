# BcsContabilidadServicios — Characterization Tests

Phase 1 pilot: Java EE 8 / TomEE 8 → Spring Boot 4.1.1 / Java 25.

These are **characterization tests**: they pin what the legacy system *actually
does*, not what a spec says it should. The legacy source is the oracle. Every
test cites the legacy `file:line` it pins.

Current state: **1,297 tests, all green, none skipped or `@Disabled`** (2026-10-15).
The evidence, canaries and deviations are in `../../../../../../TRANSFORMATION_NOTES.md`.

## Running the tests

```bash
export JAVA_HOME="/c/Program Files/Eclipse Adoptium/jdk-25.0.4.101-hotspot"   # JDK 25
cd modernized/otr-sva-optimus-corredores/BcsContabilidadServicios
mvn -o clean test

# One package or one class:
mvn -o test -Dtest='cl.bcs.contabilidad.envio.**'
mvn -o test -Dtest=CentralizacionOrchestratorTest
```

`LegacySqlParityTest` reads the legacy SQL through a relative path. When the module runs
from a copy outside the workspace, pass `-Dlegacy.sql.dir=<legacy>/BSCL/Contabilidad/JAVA/BcsContabilidadServicios/src/cl/bcs/contabilidad/sql`.
A missing oracle **fails** the test; it is never skipped.

## Adding a new case

1. **Read the legacy source.** It is the oracle; its comments are not. Every branch must have at least one test.
2. **Use concrete literal inputs and expected outputs**, and cite the legacy `file:line` in a one-line comment.
3. **Do not use `@Disabled`.** A test without an implementation must fail, not be skipped.
4. **Check that the test can fail.** Break the implementation in one small way and confirm at least one test goes red, then restore it.

## Credential safety

- No real password, key, connection string or token appears in any test.
- Fakes use same-shape values (for example `sftp.test.invalid`, keys generated in the test, `jdbc:h2:mem`).
- Live values come only from environment variables, which tests never read from the real environment:
  - SFTP: `SFTP_HOST`, `SFTP_PORT`, `SFTP_USER`, `SFTP_PASSWORD`, `SFTP_KNOWN_HOSTS`.
  - SAP B1: `SAP_B1_URL`, `SAP_B1_COMPANY`, `SAP_B1_USER`, `SAP_B1_PASSWORD`, and `SAP_B1_DB_*`.
  - Platform: `PLATAFORMA_BASE_URL`.
