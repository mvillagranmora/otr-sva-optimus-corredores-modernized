## Business Rules Preserved

### Cuota calculations
- **B-FM-CUOTA-01**: `numeroCuotas = monto / valorCuota`, scale=decimalesCuota, HALF_DOWN
- **B-FM-CUOTA-02**: `monto = numeroCuotas * valorCuota` (MathContext.DECIMAL128)
- **B-FM-CUOTA-03**: RESREINV with zero cuotas → scale=decimalesCuota+1, HALF_UP
- **B-FM-CUOTA-04**: valorCuota == 0 → error code ERROR_VALOR_CUOTA
- **B-FM-CUOTA-05**: diferido = (idMonedaInversion != idMonedaFondo)
- **B-FM-CUOTA-06**: tipoCambio = APO → ValorDolarAporte, else ValorDolarRescate

### Spread calculations
- **B-FM-SPREAD-01**: `montoReajuste = valorFactorReajuste * costoFactorReajusteRescate`, scale=8 HALF_DOWN
- **B-FM-SPREAD-02**: `spread = (cantidadRescate * valorCuota) - montoReajuste`, scale=8 HALF_DOWN (same currency)
- **B-FM-SPREAD-03**: different currency: uses paridad-converted montoReajuste
- **B-FM-SPREAD-04**: validations: all factors must be > 0

### Utility rules
- **B-FM-UTIL-01**: flujo matches solicitud on portafolio+instrumento+(regimen or empty)
- **B-FM-UTIL-02**: regimen vacio = null or ""
- **B-FM-UTIL-03/04**: WEB and EJE are web-services channels
- **B-FM-UTIL-05**: estado = CRT if certAuto=S and 0 autorizaciones, else PEN
